# Trust Minimal — MiviaLab demo landing page

**Step 1** of the MiviaLab landing page build. Generated from [ui-ux-pro-max](https://github.com/) design intelligence + [`assets/docs/mivialab-business.md`](../../assets/docs/mivialab-business.md).

## Design system

| Token | Value |
|-------|-------|
| Pattern | Minimal Single Column |
| Style | Trust & Authority |
| Type | Inter (300–700) |
| Palette | Pure black `#000` + white `#FAFAFA` + zinc borders |

Persisted rules: [`design-system/mivialab/MASTER.md`](../../design-system/mivialab/MASTER.md)

## Page structure

1. **Hero** — Ottawa studio headline + primary CTA
2. **Intro** — Mission + bilingual capability (EN / FR / 中文)
3. **Benefits** — 3 buyer outcomes (fast, secure, custom/handled)
4. **Services** — Web dev, care plan, branding, bilingual builds
5. **Portfolio** — Real client + labeled concept samples
6. **Pricing** — Build (quoted) + care plan (monthly, price on request)
7. **Team** — Studio members (demo placeholders)
8. **Contact** — Short form (primary) + WeChat secondary
9. **Footer** — Nav + subordinate channels
