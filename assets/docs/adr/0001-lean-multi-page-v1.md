# Lean multi-page IA for v1

MiviaLab’s marketing site must build trust and funnel to one contact action, with thin early portfolio and open pricing. We rejected a single-page-only site (too little room for real Work details and deep links) and a classic agency sitemap (Services / About / Pricing / Contact as peers would feel empty and split the funnel). **v1 is lean multi-page:** `/` owns persuasion; thin topics stay as landing sections; only substantive real-client work gets `/work/[slug]`; the site is English-only (bilingual is an offer capability, not a locale).
