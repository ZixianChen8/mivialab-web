# Reference

Visual and contextual reference material for agents working in this repo.

**Not for runtime.** Nothing here is served by `web/` unless explicitly copied into `web/public/`.

## What goes here

- Screenshots, mockups, and inspiration images
- Competitor or benchmark captures
- Annotated design references
- Other files agents should read or compare against when implementing

## What does not go here

- Production runtime assets → copy into `web/public/` when needed
- Source logos and raw media → `assets/images/`
- Strategy, copy, and IA docs → `assets/docs/`

## Suggested layout

```
reference/
├── inspiration/   # mood boards, sites to emulate
├── screenshots/   # captures of current or target UI
└── notes/         # optional short context files alongside images
```

Keep filenames descriptive so agents can find material without opening every file.
