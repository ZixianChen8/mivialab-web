# MiviaLab website

Production codebase for the MiviaLab marketing site. React 18 + TypeScript + Vite + Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

Shared source files (brand docs, raw images, exports) belong in `assets/`, not in this folder's public directory.
